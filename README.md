# VAT Test Data

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23076182.svg)](https://doi.org/10.5281/zenodo.23076182)

National-format VAT numbers for every country in the VAT registry, with the 2026 standard rate. Format-shaped synthetic values for fixtures; not verified registrations.

Free to use under **CC0-1.0** (public domain dedication, no attribution required).

DOI: [10.5281/zenodo.23076182](https://doi.org/10.5281/zenodo.23076182)

## Files

- `vat-small.json`
- `vat-small.csv`
- `vat-medium.json`
- `vat-medium.csv`
- `vat-large.json`
- `vat-large.csv`

Each size ships as JSON and CSV. The data is deterministic: the same size always
produces the same rows.
